# Support

Use [GitHub Issues](https://github.com/GageSorrell/VsCodeIterationMcp/issues) for reproducible bugs, feature requests, and compatibility reports.

Include:

- extension version and VS Code version;
- Windows architecture and whether the workspace is trusted;
- selected agent, scope, and workspace root;
- the command or MCP tool that failed;
- redacted error text and steps to reproduce.

Do not attach bearer tokens, agent credentials, private source code, or unredacted configuration files. The extension is local-only and does not provide a hosted support endpoint or telemetry service.

For security issues, do not open a public issue with an exploit or credential. Contact the repository maintainer through the private contact method available from the GitHub profile and include only the minimum reproduction details.
